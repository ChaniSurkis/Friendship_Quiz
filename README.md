# Friendship Quiz  
### Friendship Quiz Management System

Friendship Quiz is a backend-driven quiz system designed to create and manage friendship quizzes.  
The project allows users to participate in quizzes, authenticate securely, and receive notifications via email.

🚧 **This project is currently under development.**

---

## Overview
The project simulates a friendship quiz platform where users can answer questions and interact with the system through secured endpoints.  
It focuses on authentication, data persistence, and backend logic.

---

## Main Features
- Quiz creation and participation
- User authentication using JWT
- Secure API endpoints
- Data storage using SQL Server
- Email notifications for quiz-related events
- Modern JavaScript (ES6) implementation

---

## Technologies Used
- Node.js
- JavaScript (ES6)
- SQL Server
- JWT (JSON Web Tokens)
- Email notification service
- RESTful API architecture
